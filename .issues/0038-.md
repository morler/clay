## Summary of Changes

scope 准入已接入 OpenAI 与 Codex 的每次 HTTP 尝试（Grok 复用 OpenAI 循环）：请求前获取 scope permit，请求返回后立即释放，重试等待、刷新和工具执行期间不持有。新增 clay_scope_try_acquire 供空闲时无等待获取；clay_scope_acquire 增加排队上限（每 scope 8 个等待者）与等待时长上限（600 秒），超限返回 -1 并报错。共享对象身份、隔离与寿命沿用既有 scope 测试；新增 test_scope_admission_limits_http 验证同一 scope 下 3 个 completion 的 HTTP 在途峰值为 1。make test 通过。
