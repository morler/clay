### 本次新增的验证缺口（#89 未列，但属于同一件事）

预算测试此前只测主代理的「提示 + 工具」，**子代理的固定成本从未被覆盖**：它发送同一份基座提示 + 自己的后缀 + 更小的工具集。现在单独测量并断言：

```
subagent fixed cost: prompt 9062 + suffix 1057 + tools 6287 = 16406 B (budget 16800)
```

预算单独设为 `CLAY_SUBAGENT_FIXED_COST_BUDGET`（16800），不与主预算共用——否则主代理的余量会让"只伤子代理"的改动通过。反证：给后缀加 450 B，立刻 `prompt + suffix_bytes + subagent_bytes <= CLAY_SUBAGENT_FIXED_COST_BUDGET` 失败。

`clay_subagent_prompt_suffix()` 因此成为公开访问器，供测试测量。
